一款个性化、轻量级的 Android 文件管理器，派生自优秀的 [Amaze File Manager](https://github.com/TeamAmaze/AmazeFileManager)。

此版本正在进行修改，旨在创造一个简洁、强大且专注的文件管理体验。

## 🎯 核心功能

我的目标是构建一个具备以下特点的文件管理器：

*   **极简与轻量化：** 精简至核心功能，以确保尽可能小的应用体积和最流畅的性能。
*   **全面的网络支持：** 原生支持所有必要的网络存储协议：
    *   FTP
    *   SFTP
    *   SMB (v2/v3)
    *   WebDAV
*   **纯粹的深色模式：** 一个干净、美观的深色主题，可在任何光线条件下舒适查看。
*   **强大的 Root 浏览器：** 为高级用户提供完整可靠的 Root 权限，以管理整个文件系统。
*   **无广告，无冗余：** 完全免费、开源，且没有任何广告或不必要的功能。

## 🚧 开发状态 🚧

该项目目前正处于 **积极开发中**。

功能正在不断添加和完善。为了与项目的极简主义目标保持一致，可能会移除一些来自原版 Amaze File Manager 的功能。
